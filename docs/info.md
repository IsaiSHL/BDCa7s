## How it works

A BCD-to-7-segment decoder converts a 4-bit BCD number (0000–1001) into the signals required to illuminate the segments a–g of a display.

## How to test

Modify the first four inputs using the switches.

## External hardware

An input DIP switch and a common-cathode seven-segment display are required.
